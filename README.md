# Athlete Performance Forecasting

Machine learning project for forecasting professional draft outcomes using collegiate athlete performance statistics.

## Overview

This project evaluates athlete performance metrics and develops predictive models to estimate draft likelihood. Multiple machine learning algorithms were trained and compared using historical player statistics.

## Models Evaluated

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Evaluation

Models were evaluated using AUROC and classification metrics to determine their ability to identify draft-worthy athletes.
